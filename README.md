# AIGC-Forensics

AI 生成图像多信号融合取证检测器。输入一张图像，输出 AIGC 疑似分数、五级判定、
以及四路信号的逐项证据与解释——每一路都有独立原理，结果可解释、可复核。

```
判定: 较可能为 AI 生成（score = 0.77）
【元数据信号】     score = 0.55   无相机 EXIF（弱证据）
【频域信号】       score = 0.85   奈奎斯特角窗能量为基线 405 倍（棋盘伪影）
【噪声残差信号】   score = 0.80   残差标准差 1.26（异常平滑）
【尺寸格式启发式】 score = 0.85   512x512 命中扩散模型输出桶
```

## 为什么不是端到端深度模型

免训练的多信号融合有三条理由：

1. **可解释**：每个判定都能拆到具体证据（哪一路、哪个统计量、为什么），取证场景下这比 0.02 的准确率提升更重要；
2. **零算力门槛**：CPU 上单图分析约 0.5 秒，不依赖 GPU 与大模型权重；
3. **可扩展**：新增信号（如 C2PA 解析、PRNU 相机指纹、轻量 CNN）只需实现同样的 `analyze()` 接口注册进融合引擎。

## 四路信号原理

| 信号 | 原理 | 主要局限 |
|---|---|---|
| 元数据（权重 0.35） | 真实拍摄照片携带完整相机 EXIF；生成工具会在 XMP / C2PA / IPTC 数字源类型中主动声明 AI 来源（`TrainedAlgorithmicMedia` 等确定性标记，命中直接短路到极可能 AI） | 社交平台转存、截图同样抹掉 EXIF，无 EXIF 仅作弱证据 |
| 频域（权重 0.25） | 转置卷积解码器留下 2px 棋盘伪影，频谱特征是奈奎斯特角窗尖峰（线性功率域统计；Frank et al. 2020 频域取证思路） | 强 JPEG 压缩衰减高频；拍摄屏幕 / 周期纹理内容可能误报 |
| 噪声残差（权重 0.25） | 生成图整体异常平滑：3x3 中值滤波高通残差标准差显著低于真实照片的传感器噪声水平 | 强 JPEG 会注入块伪影（检测到后本路自动降权）；强降噪照片会误报 |
| 尺寸格式（权重 0.15） | 扩散模型按固定分辨率桶输出（512/1024 及 SDXL 常见桶、64 倍数），生成工具默认 PNG/WebP | 裁剪缩放即可规避，是最弱一路 |

融合规则：按「权重 × 置信度」加权平均；元数据出现确定性 AI 标记时直接抬高下限至 0.93。
判定阈值：≥0.80 极可能 AI / ≥0.60 较可能 AI / ≥0.40 无法判定 / ≥0.20 较可能真实 / 其余极可能真实。

## 用法

```bash
pip install -r requirements.txt

# 单图分析（人类可读报告）
python -m aigc_forensics detect image.png

# JSON 输出（便于接入流水线）
python -m aigc_forensics detect image.png --json

# 批量分析目录
python -m aigc_forensics batch ./screenshots --json

# 本地网页演示（浏览器上传 → 图形化报告）
python demo_server.py --port 8088
# 然后打开 http://127.0.0.1:8088 （仅监听本机回环地址）
```

## 测试

```bash
python tests/test_detector.py
```

测试内程序化生成 15 个样本：5 个模拟生成图特征（棋盘伪影 + 异常平滑 + 512 桶）、
5 个模拟真实照片特征（传感器噪声 + 完整 Canon EXIF + JPEG）、5 个带 XMP AI 标记。
当前结果三类完全分离：生成图 0.770 / 真实照片 0.292 / AI 标记 0.930，
另含报告结构完整性与损坏文件优雅处理检查。

## 诚实的局限声明

- **阈值是小样本经验标定**（合成样本 + 规则设计），不是大规模评测结论。上生产或写进报告前，应在真实数据集上重新标定并汇报混淆矩阵。
- **本工具输出是概率倾向，不是事实认定**。对单张图做处罚性决策（内容审核封禁等）必须有人工复核。
- 线性功率域对离群尖峰敏感：拍摄屏幕、规则纹理（布料、栅栏）可能触发频域误报——置信度加权与多路融合就是为此设计的兜底。
- 未实现 Stable Diffusion 隐水印检测：`invisible-watermark` / `pywavelets` 在当前 Python 3.13 环境无兼容发行包，且水印 bits 常量需要与官方仓库核对后才可硬编码，未核对前不实现（宁缺毋错）。

## 扩展方向

- PRNU 相机指纹：与已知相机指纹做相关性匹配，把「无 EXIF」变成可定位来源
- 轻量 CNN（CIFAKE 级别的小模型）作为第五路信号接入同一融合框架
- 在 GenImage / DRWT 数据集上重新标定阈值并汇报 ROC
